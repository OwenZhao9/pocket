# Avalanche Buildathon 提交材料

## 报名表字段

**项目名称:** Pocket

**方向:** 方向 2「消费应用与支付」

**一句话:** 口袋里的交易台——刷脸登录,选涨或跌,确认。没有助记词,没有杠杆,没有订单簿。

**问题:**
已经在链上的人想在手机上交易,在 Avalanche 上能用的只有「在手机浏览器里打开一个桌面网页」。LFJ、GMX、BENQI 全是网页,唯一的官方 iOS 应用 Core 是钱包,不是交易应用。新用户还要先装钱包、抄助记词、领水、授权——走到第一笔交易之前就流失了。

**方案:**
Pocket 是一个原生 iOS 应用(同一套代码也导出了网页版给评委验证):

- **刷脸就是钱包。** 通行密钥的 PRF 输出派生出交易私钥,私钥只在内存里,不落盘、不上服务器
- **选涨跌、选金额、确认。** 一笔交易上链,1–2 秒确认。新用户自动领到启动资金和手续费,不用领水、不用授权
- **设一条规则就走。** 止盈止损写在合约里,服务器每分钟检查一次,但只能在合约确认价格到位时触发,钱永远打回用户
- **按次付费的行情解读。** 0.01 USDC 一次,x402 协议,付款就是一次签名
- **每笔成交写一张回执到 Pocket 自己的 L1。** C-Chain 上的合约读取真实结果,经 ICM 送到 L1 记账,形成可携带的交易战绩

**亮点:**
1. Avalanche 上第一个原生移动端交易应用,通行密钥登录在真实 iOS 上跑通
2. 用到第二条评分点名的全部四样能力:性能、L1、ICM、x402
3. 安全边界是结构性的:服务器拿不到用户私钥,也挪不动用户的钱

**本次完成的部分:** 全部代码都是本次黑客松期间从零写的。合约(含 28 条测试)、Cloudflare Worker 服务端、Expo 应用(iOS + 网页)、Pocket L1、ICM 回执链路,全部在提交历史里可逐条核对。

## 演示视频脚本(约 2 分 30 秒,真机录屏)

开录前:手机连好 Wi-Fi;屏幕录制开着麦;Snowtrace 页面在 Safari 里预先打开一个标签页。

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00 | 打开 Pocket,欢迎页 | 「这是 Avalanche 上第一个原生移动端交易应用。」 |
| 0:08 | 点「刷脸创建账户」,Face ID | 「没有助记词,没有钱包插件。通行密钥就是钱包,私钥从不离开这台手机。」 |
| 0:20 | 余额从「正在发放」变成 100 pUSD | 「新账户自动拿到启动资金和手续费,不用去领水。」 |
| 0:30 | 选看涨、10 pUSD、涨跌 1%,确认 | 「选方向、选金额、设一条规则。确认。」 |
| 0:40 | 底部提示「已成交」,点开链上记录 | 「一秒多上链。这是 Snowtrace 上的这笔交易。」 |
| 0:55 | 持仓页,盈亏在动,规则引擎「X 秒前检查过」 | 「止盈止损写在合约里。服务器每分钟检查一次,但它只能在合约确认价格到位时触发,钱永远打回我的地址。」 |
| 1:15 | 行情页,付 0.01 USDC | 「两小时行情解读,按次付费,一分钱。这是 x402——付款就是一次签名,没有订阅,没有注册。」 |
| 1:35 | 结果出来,点开结算交易 | 「结算是我们自己的服务器完成的,不经过第三方。」 |
| 1:45 | 日记页,写一条,点「看看存的是什么」 | 「交易日记用通行密钥派生的另一把钥匙加密,存在手机上的只有密文。」 |
| 2:00 | 锁定,再刷脸 | 「锁定,再刷脸——还是同一个地址。」 |
| 2:10 | 平仓;切到电脑,展示 L1 回执簿 `count()` 加一 | 「每笔成交,C-Chain 上的合约读取真实结果,经 ICM 写进 Pocket 自己的 L1。这是一份伪造不了的交易战绩。」 |
| 2:25 | 回到欢迎页 | 「Pocket。口袋里的交易台。」 |

**不要说的:** 「上架 App Store」「主网」「真钱」。这是测试网版本。
